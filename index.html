Get started

First steps

Install it and go. Set up AI and the rest when you need them.

01

Install

Grab the DMG or run brew install --cask kaku, then open Kaku and start working.

02

AI setup

When you need AI, run kaku ai to use your Codex connection or configure an API service, then press Cmd + L to open chat.

03

Tools

Cmd + Shift + G for Lazygit, Cmd + Shift + Y for Yazi, and Cmd + Shift + R to mount remote files in an SSH session.

04

Config

Run kaku config to change font size, opacity, Smart Tab, close confirmation, and shortcuts right in the terminal. Anything deeper goes in Lua.

Why Kaku

It started as my own daily driver

Most of my work and life runs through the command line. I used Alacritty for a long time, but without tabs it got in the way once I started coding with AI. The other terminals I tried each had something, font rendering, window quirks, a required login, and I wanted one that works well the moment it is installed, without a pile of config first. So I built Kaku.

Questions

Common questions

How do I install Kaku?

Download the DMG, or install with Homebrew: brew install --cask kaku.

How does it compare with iTerm2, Warp, Ghostty, and WezTerm?

In short, fonts, themes, and shell tools are set up out of the box, there is no account, and AI runs on your own service. The comparison page covers each one in detail.

Is Kaku paid?

No, Kaku is an MIT-licensed open source project.

Does Kaku run on Windows or Linux?

Not yet. For now the focus is making it great on the Mac.
