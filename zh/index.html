Remote

离开 Mac，也能接着用

在 Mac 上运行 kaku remote，用生成的链接配对浏览器，就能继续操作正在运行的终端和 AI 会话，标签、分屏和文件传输也都在。Mac 需保持开机联网，浏览器与 Kaku 之间的内容经过端到端加密。

日常使用

标签和分屏，还是 Mac 上那套快捷键

⌘T 开标签，⌘D 分屏，⌘1 到 ⌘9 切换；右键可快速复制、粘贴、搜索或发起 AI 对话。退出后再打开 Kaku，窗口、分屏和工作目录都会原样恢复。

上手

从这里开始

装完直接用，AI 服务和其他设置等用到时再配。

01

安装

下载 DMG 或运行 brew install --cask kaku，装完跑一次 kaku doctor，看看 app、PATH 和 shell 集成是否正常。

02

AI 设置

运行 kaku ai，沿用 Codex 的连接或配置自己的 API 服务，之后按 Cmd + L 就能打开 AI 对话。

03

工具

Cmd + Shift + G 打开 Lazygit，Cmd + Shift + Y 打开 Yazi，在 SSH 会话里按 Cmd + Shift + R 可以挂载远端文件。

04

配置

运行 kaku config，在终端里改字号、透明度、Smart Tab、关闭确认和快捷键，更细的地方用 Lua 覆盖。

为什么是 Kaku

先是我自己天天在用

我工作和生活里的事大多在命令行里完成。之前用了很久 Alacritty，但它没有多标签，做 AI 编码时很不方便；其他几款也试过，总有字体渲染、窗口细节或强制登录这类小遗憾。我想要一个开箱即用、不用先写一堆配置的终端，于是做了 Kaku。

问答

常见问题

怎么安装？
从 GitHub Releases 下载 DMG，或用 Homebrew 安装：brew install --cask kaku。
和 iTerm2、Warp、Ghostty、WezTerm 比有什么不同？
简单说就是字体、主题和 Shell 工具开箱配齐，无需注册账号，AI 服务直连你自己的配置；每一款的具体差别写在对比页里。
Kaku 收费吗？
不收费，Kaku 是 MIT 协议的开源项目。
支持 Windows 或 Linux 吗？
暂时不支持，眼下先把 Mac 上的体验做好。
