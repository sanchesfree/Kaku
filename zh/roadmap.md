# 路线图

V0.24.0 带来了 kaku remote，可以在另一台电脑的浏览器里用这台 Mac 的终端，V0.25.0 又加上了 agent 标题、不用设置的 Claude Code 通知和 AI 对话控制；这一轮继续打磨终端设置易用性、收紧 AI 沙箱规则，并优化安装与更新体验。
